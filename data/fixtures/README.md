# Test fixtures

Not part of the published catalog. `index.json` lists the suites the store
sells; this directory holds documents that exist only to exercise a path.

- `acceptance-run.json` — the minimal three-member suite used for the
  end-to-end install/uninstall runs. It was published as a real card until the
  member-count rule (2–10) made it obvious it was a test case wearing a product
  card: it duplicated two of `daily-driver`'s members and answered no user's
  question. To install it again, point `catalogFile` at a catalog that lists it.
